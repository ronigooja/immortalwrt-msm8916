# Task State Template

Use this template only for long-running, paused, high-risk, or explicitly
recorded work. Most small tasks should not create a task-state file.

Saved task states belong under:

`docs/task-states/YYYY-MM-DD-short-task-name.md`

Do not create `docs/task-states/` until there is a real state file to save.

## Task

One-sentence description of the task.

## Type

Feature / Optimization / Refactoring / Troubleshooting

## Phase

Context / Design / Implementation / Verification / Documentation / Handoff

## Goal

The concrete final outcome.

## Files Read

- `path`

## Files Changed

- `path`

## Decisions

- Decision or constraint already established.

## Verification

Run:

- Command or check performed.

Not run:

- Command or check skipped, with reason.

Result:

- Verification result.

## Risks

- Remaining risk or uncertainty.

## Next Step

The exact next action for a future conversation.
